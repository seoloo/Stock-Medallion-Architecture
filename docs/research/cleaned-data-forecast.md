# 정제한 인계 데이터로 계산한 20종목 예상

**오염·비표준 데이터를 정제한 뒤, 그 데이터의 실적·현금·주가·수급을 연결해 다음 20거래일의 시장 대비 방향을 예상한다.** 추가 수집한 10월 자료는 이 계산에 사용하지 않았다.

- 예상 기준일: 2026-06-30. 이 날짜까지 관측된 데이터만 사용한다.
- 예상 대상: 기준일 이후 20거래일 동안 종목 수익률이 같은 시장 지수보다 강할지, 약할지, 혼조일지에 대한 팀의 가설.
- 입력: 고정 인계본 Silver의 기업·재무 보고서·지표와 기존 Gold의 가격·지수·투자자 수급.
- 결과: **강세 예상 4종목 / 혼조 예상 12종목 / 약세 예상 4종목**.

## 정제가 결과에 연결되는 과정

| 정제·검증 | 분석에서 필요한 이유 | 실제 사용하는 근거 |
|---|---|---|
| 기업·종목 코드 표준화와 연결 | 재무와 거래 데이터를 같은 기업에 연결 | `stock_cd`, `fin_rpt_id` |
| YTD·PRIOR_YTD·연결/별도 구분 | 다른 길이의 기간·다른 범위의 회계를 섞지 않음 | 같은 보고서의 매출·영업CF 전년동기 값 |
| 공시일·거래일 시점 검증 | 당시에 알 수 있던 재무만 사용 | `disclosure_date < as_of` |
| 수급 단위·투자자 계층 표준화 | 외국인·기관 합계를 중복 없이 계산 | 최상위 외국인·기관의 20관측 순매수 |
| NULL·0·검토 상태 분리 | 빠진 숫자를 0으로 오해하지 않음 | 필수 입력·기간 적격·현금흐름 검증 플래그 확인 |

기준일의 20종목은 모두 사용한 보고서의 공시·동일기간 비교·현금흐름 검증 조건을 충족했다. 전체 데이터에 남아 있는 기간 미검증 61보고서를 정상값으로 바꿔 사용한 것이 아니다.

## 공개한 예상 규칙

다섯 신호가 각각 양수인지 확인한다. 0은 양수에 포함하지 않는다.

1. 동일 보고서 누적 매출의 전년동기 성장률.
2. 공시 직전 거래일부터 기준일까지의 종목 수익률에서 같은 구간 시장 지수 수익률을 뺀 값.
3. 동일 보고서 누적 영업현금흐름의 전년동기 증감액.
4. 최근 20개 거래 관측의 외국인 순매수 합계.
5. 최근 20개 거래 관측의 기관 순매수 합계.

**양수 4~5개면 시장 대비 강세, 2~3개면 혼조, 0~1개면 시장 대비 약세를 예상한다.** 동일 가중치와 경계값은 팀이 정한 탐색용 가설이다. 미래 20일의 실제 성과로 이 규칙의 적중률을 검증한 것은 아니며, 통계적으로 보장된 상승 확률을 뜻하지 않는다. 절대 주가 상승과 시장 대비 강세도 구분한다.

이 예상은 6월 말에 알 수 있던 정보로 만든 당시 시점의 가설이다. 10월 현재에 대한 실시간 예상이나, 10월 자료로 6월 예상의 정답을 확인한 결과가 아니다. 기존 표준화·SQL PASS는 데이터 처리 정확도의 증거이며 미래 주가 예측 정확도의 증거로 바꾸어 쓰지 않는다.

## 대표 결론

- **삼성전자: 시장 대비 강세 예상.** 매출 성장·공시 후 초과성과·영업CF 증가·기관 순매수가 양수여서 4/5다. 외국인 순매도라는 반대 근거도 함께 공개한다.
- **SK하이닉스: 혼조 예상.** 매출·공시 후 초과성과·영업CF는 양수지만 외국인·기관은 순매도여서 3/5다. 주가 상승이 관측됐어도 수급까지 함께 지지하는 상승으로 보지 않았다.
- **현대차: 시장 대비 약세 예상.** 매출은 늘었지만 시장 대비 성과·영업CF 증감·외국인·기관 수급이 양수 조건을 충족하지 않아 1/5다.

이렇게 정제한 데이터가 **어느 기업의 어떤 수치 → 어떤 신호 → 어떤 예상**으로 연결되는지 재현할 수 있다. 가격 자체의 고평가·과열 여부는 [10월 추가 수집 자료를 이용한 별도의 확장 분석](assessment.md)에서 다룬다.
